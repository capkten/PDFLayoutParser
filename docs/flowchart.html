PDFLayoutParser 流程图

下面这两张图分别展示整体流水线，以及 table_extractor.py 的详细分支。

1. 整体流水线

graph TB A[输入 PDF] --> B[Loader.load] B --> C[Document 和 Page 元数据] C --> D[逐页处理] D --> E[TextExtractor] E --> E1[读取 page.get_text dict] E1 --> E2[恢复 Block Line Word Char] E2 --> F[LayoutMapper] F --> F1[生成 text LayoutElement] F1 --> G[TableExtractor] G --> G1[线框法提取] G1 --> G2[PyMuPDF 回退] G2 --> G3[ML 补充] G3 --> G4[文本对齐补充] G4 --> H[ImageExtractor] H --> I[Seal 匹配] I --> J[LayoutBuilder] J --> J1[去掉表格内重复文本] J1 --> J2[追加 table image seal] J2 --> K[排序并写回 page.layout_elements] K --> L[RenderEngine] L --> M[写 page PNG] M --> N[JSONWriter 和 MarkdownWriter 写单页] N --> O{所有页结束} O -->|否| D O -->|是| P[写 output.json] P --> Q[写 output.md] Q --> R[写 timings.json] R --> S[返回 Document]

2. 表格提取详细图

graph TB A[TableExtractor.extract] --> B[清空调试信息] B --> C{页面是否存在明显表格线} C -->|是 有线表格| D[线框法提取] D --> E[提取可见绘图矩形] E --> F[合并相邻线段] F --> G[按连通分量找区域] G --> H[建格] H --> I[按词回填文本] I --> J[合并过碎列] J --> K{结果是否可靠} K -->|否| L[PyMuPDF 回退] K -->|是| M[保留线框结果] C -->|否 无线表格| N[文本对齐提取] N --> O[收集文字行] O --> P[按行聚类] P --> Q[推断列参考线] Q --> R[生成 text_alignment 表格] L --> S{开启 ML} M --> S S -->|是| T[ML 补充表格] S -->|否| U[继续合并] T --> U R --> V{与现有表格重叠} U --> V V -->|否| W[加入结果集] V -->|是| X[丢弃重复表格] W --> Y[返回 tables] X --> Y
