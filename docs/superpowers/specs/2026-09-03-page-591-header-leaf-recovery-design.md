# 页 591 跨行前置表头下的叶子列恢复设计

## 目标

修复 `fix/zh_all_table_pages.pdf` 页索引 `591` 的中文无线表格整表丢失。目标表应恢复为 `wireless_span_recovery`、`29x11`，同时保持页 923 已有的严格叶子表头恢复规则及其他中文/混合页面行为。

## 根因

模型以 `0.9806` 置信度正确检测 bbox `[55.6, 120.2, 786.6, 508.1]`。模型框内有 80 个 native span，形成 63 个 atom，输出模式正确识别为 `columnar`。

当前基础推断得到 6 个稳定列带，附注救援后为 7 列；正文全空的“其他权益工具、资本公积、减：库存股、专项储备”没有稳定轨迹。`rescue_header_only_leaf_bands()` 要求同一最低表头层覆盖全部稳定列带，但“项目”位于上一表头层并应跨越最低表头层，因此最低层只覆盖稳定列 3 至 7。该层被整体拒绝，四个标题分别挤入已有槽位，形成 `R2C3` 和 `R2C4` occupancy conflict，恢复器返回空结构。

## 方案

保留现有“同层覆盖全部稳定列带”的严格分支；只在该分支不成立时增加跨行前置表头补充分支。

补充分支必须同时满足：

- 当前层是 cutoff 内最低的、含未匹配非结构性标题的表头层；
- 当前层至少覆盖两个稳定列带，并且覆盖的稳定列带形成连续后缀；
- 缺席的稳定列带全部位于当前层已覆盖范围左侧，不允许中间或右侧稳定列无标题；
- 上一层存在 atom 对缺席的前置稳定列带提供唯一覆盖，证明它们是跨行结构列；
- 当前层没有跨越多个稳定列带的父标题；
- 未匹配候选至少两个，按 x 单调排列，均位于表格 region 的既有左右结构边界内；
- 候选不是年份、单位、百分号、纯数字、占位符或附注引用，并与现有列带及相邻标题保持明确间距；
- 所有候选作为一个组一次性加入并重新编号；任一候选不成立则整组放弃。

该规则只消费 native span、atom、列带和表头拓扑。不得调用 `page.get_text("words")`，不得进入 `extract_zebra()` 或 legacy `_rebuild_text_aligned_table()`。

## 数据流与冲突处理

调用位置保持在 `recover_cells_from_region()` 的附注列救援之后、列标注之前：

```text
native span -> atom -> 稳定列带 -> 附注列救援
-> 叶子表头列救援 -> annotate_columns -> physical grid
-> occupancy conflict -> logical grid -> 空槽位物化
```

新增列带不绕过现有冲突检查。补列后的物理或逻辑网格存在冲突时，结果仍不得输出。

## 测试与验收

- 正例：前置一列标题只出现在上一层，最低层覆盖稳定列后缀，并包含两个缺失叶子标题；应整组恢复。
- 反例：最低层漏掉中间稳定列，必须拒绝。
- 反例：上一层不能唯一证明缺席的前置稳定列，必须拒绝。
- 既有 page 923、父表头、孤立说明、近邻碎片测试保持通过。
- 独立重跑页索引 591，核对 `29x11`、319 个逻辑槽位唯一占用、0 冲突、bbox 不吸收标题和签字栏，并检查最终 PNG。

## 非目标

- 不降低普通列带的重复支持门槛；
- 不按具体表头文字或页码硬编码；
- 不修改 span 到 atom 的组合策略；
- 不放宽 occupancy conflict；
- 不改英文、斑马纹或有线表格路径。
