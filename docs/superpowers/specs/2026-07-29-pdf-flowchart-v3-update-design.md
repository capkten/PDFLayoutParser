# PDF 解析流程图 v3 调整设计

## 目标

调整 `PDF解析完整算法流程图_v3.svg`，明确表格页前置筛选、Span 特征复用，以及模板恢复失败后的全自动处理方式。

## 流程调整

### 1. Span 特征预处理独立化

将无线表格恢复器中的“原始 Span 顺序 + 空间 + 字体样式”提取为独立共享模块。模块位于 `Page Object IR` 之后、表格区域检测之前。

该模块输出同时供两处复用：

- 表格页逻辑筛选；
- 无线表格恢复器。

无线表格恢复器不再重复执行 Span 特征预处理，仅消费共享结果完成候选单元格、行列角色和合并格恢复。

### 2. 增加表格页逻辑筛选

在 Span 特征预处理之后、YOLOv8-OBB 表格区域检测之前增加“表格页逻辑筛选”判断节点。

- 判断为表格页：进入 YOLOv8-OBB 表格区域检测，并继续执行表格结构恢复流程；
- 判断为非表格页：跳过表格区域检测和全部表格结构恢复逻辑，直接进入普通页面结构化输出路径。

页眉/页脚识别与图片/图形区域确定仍面向全部页面，不受表格页筛选结果影响。

### 3. 移除人工复核运行分支

模板结果校验失败后不再进入人工复核，改为：

`打印错误日志 → 保留失败状态与候选对象 → 写入置信度与问题清单`

该分支不阻塞页面级结构化输出。流程图中不再包含运行时人工处理节点。

## 调整后的关键数据流

```text
Page Object IR
├─ 全部页面 → 页眉/页脚识别
├─ 全部页面 → 图片/图形区域确定
└─ Span 特征预处理
   ├─→ 表格页逻辑筛选
   │   ├─ 是 → YOLOv8-OBB 表格区域检测 → 表格结构恢复 → Table IR
   │   └─ 否 → 跳过表格检测与恢复 → 普通页面结构化输出
   └─→ 无线表格恢复器复用

模板校验失败
→ 打印错误日志
→ 保留失败状态与候选对象
→ 置信度与问题清单
→ 页面级结构化输出
```

## 验收标准

- SVG 中存在独立的 Span 特征预处理模块；
- Span 特征输出同时连接表格页筛选和无线表格恢复器；
- 只有筛选命中的页面进入 YOLOv8-OBB 表格检测；
- 非表格页仍经过页眉/页脚及图片/图形区域处理；
- 非表格页跳过表格检测和表格恢复；
- 模板校验失败分支仅记录日志和问题状态，不出现人工复核；
- 所有新增节点和连线无明显遮挡、交叉歧义或文字溢出。
