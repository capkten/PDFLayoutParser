# 第 184 页无线表格结构修复设计

## 目标

修复中文和混合页面 native-span 无线表格恢复中的分隔线、短占位符、列槽冲突和多行首列问题。`fix/zh_all_table_pages.pdf` 第 184 页的目标结构为：顶部 `3x3`、中部 `7x7`、底部 `5x7`。

纯 `-----`、`=====` 是排版线，不属于逻辑表格行；短 `---` 是单元格空值，占据并证明对应列。

## 根因

1. separator 字符集漏掉 ASCII `=`，长等号线进入行聚类。
2. separator 过滤按整行总覆盖判断，把同一行多个短 `---` 空值一起删除。
3. 短占位参与普通词间距统计和同一 native line 文本连接，导致列间距被当作词间距。
4. 横向重叠 component 被宽文本条桥接，`比例`、`坏账准备`落入同一列带。
5. grid 已报告同槽位冲突，但 recoverer 忽略 issues 并继续输出。
6. 多行首列标签的实际 bbox 间距约为 9.48pt，超过当前 `0.72 * font_size` 阈值。

## 设计

### Span 分类

在 `text_runs` 中明确区分：

- `rule_line`：内容仅由分隔字符构成，去空格后长度大于 3；进入文本条构建前删除。
- `placeholder`：内容是 1 至 3 个短横线；保留为独立 atom。
- `content`：其他文本。

ASCII `=`、全角 `＝` 和现有横线字符统一纳入分隔字符集合。

### 文本条构建

- `normal_word_gap` 只使用 content span 估计。
- placeholder 与任意相邻 span 存在正间距时不得连接。
- 普通连接距离不超过既有 fallback，即 `max(3.5, 0.8 * min_font_size)`；统计 gap 只能收紧该限制，不能放大它。
- 保留现有数字字段和美元符号保护规则。

### 列带与冲突

content 和 placeholder 都进入列带推断。短 `---` 的重复 x 位置为没有实际金额的列提供支持，从而恢复两组 `账面余额 / 比例 / 坏账准备` 六个叶子列及项目列。

列边界必须先于单元格归属在表级推断，不能由某一行的 span 数量或局部间距直接产生。一个有效叶子列边界通常至少需要两个不同 y 层级的独立支持，例如重复的左右对齐轨道、叶子表头与正文或 placeholder 的共同支持、重复的数值/百分比/短横线轨道，或对称的兄弟表头拓扑。只在一行出现的局部空隙视为无效边界。因此，“比例”和“坏账准备”由表头及多行 `---` 轨道分开；“合”和“计”之间没有其他行支持的内部边界，二者仍属于同一项目列槽位。

边界确定后再把原子 text run 分配到叶子列槽位。父级表头可以覆盖多个叶子列；只有多个 fragment 已落入同一槽位且槽内不存在有效边界时，才允许聚合为一个 cell。

`build_grid()` 的初始 issues 继续作为诊断信息，因为同一 cell 的原生碎片可能在后续合法合并。完成同槽位和多行合并后重新检查最终占位；若仍有多个 cell 占用同一槽位，本次恢复返回空结果，不输出自相矛盾的网格。测试要求第 184 页最终占位无 conflict。

### 多行单元格

保持同列、相邻物理行、native flow 连续、脚本兼容、非纯数值和横向重叠等现有条件，只把最大垂直 gap 从 `0.72 * font_size` 放宽到 `1.0 * font_size`。第 184 页中间表的三段首列文本合并为一个 rowspan=3 的逻辑 cell，逻辑网格压缩为 7 行。

### 同槽位文字

顶部表“合”“计”属于同一 source block/line、native flow 连续且已落在同一槽位。允许同槽位 CJK fragment 在间距不超过 `2.1 * font_size` 时连接，避免保留两个占用同一 cell 的文字对象。该规则不用于不同槽位，也不参与列带推断。

## 验证

- text-run 单元测试覆盖 ASCII `=` 长线、长横线、多个短 `---`、placeholder 不连接、gap 上限和中文正常紧邻片段。
- merge 单元测试覆盖 9.48pt 多行首列合并、真实数据行不因 flow 不连续而合并、同槽位宽字距 CJK 合并。
- recoverer 测试覆盖 grid conflict 不被静默接受。
- 重跑第 184 页，确认语言为 `mixed`，三表 source 均为 `wireless_span_recovery`，结构依次为页面顶部 `3x3`、中部 `7x7`、底部 `5x7`，不存在同槽位冲突或合并的“比例坏账准备”。
- 检查 JSON、Markdown 和 PNG，并运行相关无线结构测试与 `git diff --check`。

## 非目标

- 不恢复旧 `_rebuild_text_aligned_table()`。
- 不写第 184 页坐标、固定列数或中文表头词典特例。
- 不修改英文无线表格和有线表格路径。
