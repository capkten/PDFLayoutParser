# PDF 解析流程图 v3 样式重排设计

## 目标

在不改变现有算法节点、判断含义和数据流的前提下，对 `PDF解析完整算法流程图_v3.svg` 做系统级视觉重排，提高整体阅读顺序、文字可读性和旁路辨识度。

## 画布与总体结构

- 画布宽度保持 `2400`；高度由 `1980` 增加到约 `2280`，最终高度可根据渲染结果在 `2240–2320` 范围内微调。
- 保留 A–E 五层水平分区。
- 统一外边距、分区间距和内部网格，不改变节点所属分区。
- 分区标题下方保留独立净空，主线、总线和连接圆点不得进入标题区域。

## 分区布局

### A. 原生页面对象层

- 所有阶段节点使用统一高度和垂直基线。
- 输入、处理步骤和 `Page Object IR` 保持明确的同级阶段关系。
- 使用等距水平排列，避免末端 IR 节点显得像附注。

### B. 页面区域构建

- 使用两行布局。
- 第一行依次排列：页眉/页脚规则识别、Span 特征预处理、表格页逻辑筛选、表格区域检测、图片/图形区域确定。
- 第二行排列区域冲突消解与 `Page Region IR`。
- Page Object IR 的总线位于分区标题净空下方，不穿越标题。
- “否：跳过 OBB”进入区域冲突消解，语义和现有流程保持一致。

### C. 表格结构恢复协调器

- 表格区域入口和“线证据是否充分”节点上移，减少顶部空白。
- 有线、无线、模板恢复器使用等宽三列。
- 三个校验节点与对应恢复器严格对齐。
- 成功路径对称汇入统一 `Table IR`。
- 有线失败到无线、无线失败到模板，均使用固定的列间回退通道。
- Span Feature IR 使用左侧专用数据通道接入无线恢复器，不穿过节点或文字。

### D. 统一输出与质量门

- 保持单行输出链。
- 节点统一宽高、基线和间距。
- 表格路径进入二维矩阵节点；模板失败日志进入问题清单。
- 非表格页旁路直接进入页面级结构化输出。

### E. 工程闭环

- 增加分区高度。
- 将现有无框短语改为统一的小步骤卡片。
- 卡片按照中间快照、失败可视化、金标、回归集、指标依次排列。
- 反馈线使用独立通道返回问题清单，不贴分区边框。

## 旁路与连线

- 在画布右侧预留两个相互分离的专用通道：
  - 非表格页旁路；
  - 模板失败日志旁路。
- 两条通道保持固定间距，不贴画布或分区边框。
- 主流程使用实线；失败和跳过路径使用棕红虚线；共享数据使用蓝色虚线；工程反馈使用灰色虚线。
- 所有折线使用统一转折半径或视觉间距，箭头不得穿过标题、正文、标签或卡片。
- 连线标签使用统一字号、白色底板和固定内边距。

## 视觉规范

- 统一卡片圆角、边框宽度和内边距。
- 使用三级文字：分区标题、节点标题、正文/辅助说明。
- 放大正文与连线标签的最小字号，保证整图缩放查看时仍可辨认。
- 保留现有语义颜色，但降低背景饱和度，收敛到以下类别：
  - 蓝色：输入、共享数据与 IR；
  - 绿色：规则和区域处理；
  - 紫色：模型与模板；
  - 橙色：无线恢复；
  - 红色：判断与校验；
  - 黄色：日志异常出口。
- 主流程连线提高对比度，避免节点边框强、流程线弱。
- 不新增图例，颜色含义继续通过节点文案和流程位置表达。

## 不变项

- 不修改算法节点含义。
- 不改变表格页筛选、OBB 检测、区域汇合和表格恢复的先后关系。
- 非表格页仍执行页眉/页脚与图片/图形区域处理。
- 非表格页仍跳过 OBB 检测和 C 层表格恢复。
- 模板校验失败仍打印错误日志并写入问题清单，不引入人工复核。

## 验收标准

- 画布宽度为 `2400`，高度位于 `2240–2320`。
- A 层同排节点等高并对齐。
- B 层标题区域无连线、圆点或标签侵入。
- B 层第一行节点和第二行汇合节点形成清晰网格。
- C 层三列恢复器、校验器和成功汇合路径对称。
- Span Feature IR 蓝色通道不穿过节点或文字。
- 两条右侧旁路清楚分离，不贴边、不互相覆盖。
- D 层节点等宽等高，连接顺序清晰。
- E 层使用统一步骤卡片，反馈线具有独立通道。
- 不存在文字溢出、箭头穿字、标签遮挡、节点出界或流程语义变化。
