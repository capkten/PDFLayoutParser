# 表头附注窄列与年度父表头恢复设计

## 目标

修复无线中文表格在第 591 页上的表头结构恢复：恢复 `附注五` 的独立窄列，并将居中的 `2014年度` 识别为其后连续 9 个叶子列的父表头。文字保持原始 bbox 和视觉居中位置，空槽继续作为独立结构输出。

## 已确认根因

第 591 页当前走 `columnar` native-span 路径，表头截止位置约为 `y=144.28`。`2014年度` 的 native atom bbox 为 `[494.59, 120.26, 523.63, 128.93]`，中心约为 `509.11`，当前只被分配到第 6 列，`colspan=1`。

现有逻辑有两个不同职责：

1. `header_topology.annotate_columns()` 负责在 atom 阶段推断横向 `colspan`。
2. `logical_grid.merge_header_spans()` 只处理已经存在 `colspan > 1` 的父表头，并向下扩展已证明的 `rowspan`；它不会从空槽反向推断横向父表头。

本页的前置推断未通过，原因包括：

- 年份结构识别只匹配纯四位年份，`2014年度` 不属于该模式。
- 通用居中父表头规则把候选组宽限制在文字宽度约 `1.55~3.05` 倍，而本页目标组覆盖 9 个叶子列，远宽于该限制。
- `附注五` 只有表头支撑，没有正文重复轨迹，未形成列带；它被最近列回退规则错误吸附到第一个数据列，导致年度父表头候选与同层文字产生网格冲突。

因此，后续 `materialize_empty_cells()` 只是逐个物化空槽，无法触发横向合并。

## 目标物理网格

本页按 PDF 原生布局恢复为 11 列：

| 列范围 | 内容 | 结构 |
| --- | --- | --- |
| 第 1 列 | 项目 | 左侧标题列 |
| 第 2 列 | 附注五 | 表头专用窄列，正文通常为空 |
| 第 3~11 列 | 实收资本至所有者权益合计 | 连续的 9 个叶子列 |

`2014年度` 占第 3~11 列，`colspan=9`。其 atom bbox 不改写，因此文字仍以原始位置呈现；列占用范围由 `column_start`、`column_end` 和 `colspan` 表示。

## 设计

### 1. 恢复表头专用附注列

在已有稳定列带完成初始推断、裁剪和稀疏列救援之后，增加一个只消费 native atom 的表头窄列恢复步骤：

- 只考虑表头截止线以内的附注/引用类 atom；
- atom 不与现有列带有效重叠；
- atom 位于左侧标题列与第一个数据列之间的首个列间空隙；
- 将其恢复为 `kind="header_only_note"` 的列带，并按 x 坐标重新编号；
- 该列进入物理网格和空槽物化，但从主叶子列推断集合中排除。

附注识别扩展为通用的中文/英文 note-reference 形式，不按具体业务文字硬编码。正文中的普通附注文字不会因为位于其他列间空隙而新增列。

### 2. 从完整物理叶子层推断宽父表头

在 `annotate_columns()` 的现有两叶子、居中和混合子组规则之前增加一个通用几何判定：

- 使用所有物理叶子列带，包括被标记为 `sparse_body` 但在表头拥有真实叶子文字的列；
- 对当前 atom 下方的同一表头层按物理列分配子标题；
- 只接受覆盖连续列号、每个目标列都有非空叶子证据的候选组；
- 候选组至少包含 3 个连续叶子列；
- 父标题中心与候选物理列组中心必须在比例容差内对齐；
- 同层其他 atom 的实际 bbox 不得占用候选组；
- 存在缺列、间断、同层冲突或多个中心同样接近的候选时，拒绝推断。

该规则不识别 `2014年度` 等业务词，只根据表头层级、连续物理列和中心关系判定。成功后设置 atom 的 `column_start`、`column_end` 和 `colspan`，不合并文字、不读取 `page.get_text("words")`。

### 3. 保持后续网格职责

调用顺序保持为：

```text
native span
  -> atom/text run
  -> 初始列带
  -> header-only note 列恢复
  -> 表头叶子列细化
  -> 表头 atom 列/跨度标注
  -> 物理 grid
  -> 逻辑 grid
  -> 已证明的 rowspan 扩展
  -> 空槽逐格物化
```

`merge_header_spans()` 不承担新的横向推断职责，`materialize_empty_cells()` 不合并相邻空槽。所有跨度调整后继续使用现有 occupancy 检查，冲突结果不得进入最终输出。

## 测试设计

先在 `tests/test_wireless_structure_header_topology.py` 增加失败用例，覆盖：

1. 表头专用附注 atom 恢复为独立窄列，且不改变正文数据列分配。
2. 短的居中顶层标题在完整连续 9 叶子列上恢复 `colspan=9`，bbox 保持不变。
3. 叶子列不完整或存在同层文字实际占用时拒绝跨度推断。
4. 原有两叶子、混合子组、稀疏列和空槽物化测试继续通过。

测试必须先看到目标用例因当前实现失败，再加入最小生产代码并验证变绿。
