# 无线表格空单元格物化设计

## 目标

中文和混合页面完成 native-span 逻辑网格恢复后，输出完整的矩形单元格集合。没有文字但被有效行列边界切出的槽位也必须生成独立 `Cell(text="")`，不得因为缺少 span 而缺失或与相邻空槽合并。

第 184 页中部 `7x7` 表应输出 49 个逻辑槽位，底部 `5x7` 表应输出 35 个逻辑槽位，顶部 `3x3` 表应保持 9 个槽位。

## 数据流

保持现有流程直到逻辑网格完成：

```text
native spans
→ 原子 text runs
→ 行列边界
→ 非空 cell 分配与合法合并
→ 逻辑行压缩
→ 最终占位冲突校验
→ 物化未占用空槽
→ Project Cell 转换
```

空槽物化不读取 page words，不参与 span 合并、边界推断或逻辑行压缩。

## 空槽规则

- 遍历最终 `row_count x column_count` 的全部逻辑槽位。
- 已被非空 cell 的 `rowspan/colspan` 覆盖的槽位不再生成空 cell。
- 其余未占用槽位各生成一个 `text=""`、`rowspan=1`、`colspan=1` 的 cell。
- 相邻空槽始终保持独立，不推断空白 rowspan 或 colspan。
- 已有非空 cell 的文字、bbox、rowspan 和 colspan 不变。

## 空槽几何

空 cell 需要稳定 bbox 供 JSON 和可视化使用：

- 列外边界使用表格 region 的 `x0/x1`。
- 相邻列的内部边界使用左列带 `x1` 与右列带 `x0` 的中点。
- 行外边界使用表格 region 的 `y0/y1`。
- 每个逻辑行以其覆盖的物理行 y 中心均值作为轨道，相邻逻辑行内部边界取轨道中点。

可视化对 `wireless_span_recovery` 继续使用推断网格矩形，不能因为补齐后 cell 数量等于 `rows * cols` 就退回直接绘制混合的文字 bbox/空槽 bbox。

## 验证

- 单元测试覆盖缺失槽位补齐、已有 rowspan/colspan 覆盖区不重复补格、相邻空格保持独立。
- recoverer 测试确认完整矩形网格被转换为项目 `Cell`。
- 重跑第 184 页，确认三表 cell 数分别为 9、49、35，所有槽位占用恰好一次。
- PNG 中中部和底部两层表头横线贯穿全表，七列竖线穿过所有空槽；核心结构仍为 `3x3`、`7x7`、`5x7`。

## 非目标

- 不改变已有表头文字所属列。
- 不为“年末数/年初数”推断 colspan。
- 不回读 page words。
- 不修改英文和有线表格路径。
