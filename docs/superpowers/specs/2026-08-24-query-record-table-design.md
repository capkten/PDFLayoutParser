# 机构查询记录表恢复设计

## 目标

将个人征信报告中的“机构查询记录明细”恢复为稳定的四列表格，支持机构名称换行、页面内候选表分裂以及跨页续表。

## 方案

在 `PersonalCreditReportTableExtractor` 中增加查询记录专用恢复阶段。先识别包含“编号、查询日期、查询机构、查询原因”的候选表，再以四列的 x 坐标骨架重新整理记录：第一列数字表示新记录；没有编号且位于机构列的文本合并到上一条机构字段。多个相邻候选表按列骨架和 y 连续性合并。跨页时，如果下一页没有表头但首列继续出现编号且列坐标一致，则追加到上一页的逻辑表。

## 边界

只作用于个人征信 extractor 识别出的查询记录，不放宽通用文本区域检测规则；普通说明段落和其他表格保持现有行为。

## 验收

- `PDFsam_merge1.pdf` 的编号 1–12 在一个查询表中，机构换行文本合并。
- `PDFsam_merge3.pdf` 的编号 1–43 在一个跨页查询表中，机构换行文本合并。
- 现有表格测试不回归。
